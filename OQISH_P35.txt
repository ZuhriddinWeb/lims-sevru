---------------------------------------------------------------------------
 A) LOKALDA (E:\ai projects\lims-sevru), PowerShell
---------------------------------------------------------------------------
  1. Expand-Archive -Path "$env:USERPROFILE\Downloads\paket35_video.zip" -DestinationPath "E:\ai projects\lims-sevru" -Force

  2. VIDEO FAYLINI QO'YING. G:\LIMS dagi videolardan SUBTITRSIZ («toza») nusxasini oling
     (subtitr endi alohida, .vtt faylda) va shu nom bilan ko'chiring:
       Copy-Item "G:\LIMS\<toza_video_nomi>.mp4" "public\manuals\LIMS_video_uz.mp4"
     Faqat subtitrli nusxa bo'lsa ham ishlaydi — u holda pleyerda «CC» (subtitr) tugmasini o'chiring.

  3. Hajmini tekshiring:
       "{0:N1} MB" -f ((Get-Item public\manuals\LIMS_video_uz.mp4).Length / 1MB)
       - 95 MB dan kichik — git orqali (4-qadam), hamma serverga o'zi boradi;
       - 95 MB dan katta — GitHub qabul qilmaydi (100 MB chegara). Shunda .gitignore oxiriga:
             /public/manuals/LIMS_video_uz.mp4
         qo'shing va videoni har serverga qo'lda ko'chiring (B-3).

  4. npm run build
     Select-String -Path public\build\assets\*.js -SimpleMatch -Pattern 'LIMS_video_uz.mp4' -List | Select-Object Path
       → kamida bitta fayl
     Brauzerda (lokal sayt) «Foydalanish yo'riqnomasi» → video, subtitr, bo'limlar.
     git add -A
     git add -f public/build
     git commit -m "Paket 35: video qo'llanma, jamlanma hisobot bo'sh kun tuzatish"
     git push

---------------------------------------------------------------------------
 B) SERVERDA (VS Code, \\192.168.26.8\xampp\htdocs\LIMS, terminal)
---------------------------------------------------------------------------
  1. git fetch origin
     git reset --hard origin/main
     php artisan optimize:clear
  2. IIS bo'lsa (public\web.config bor) — public\web.config ni oching, <staticContent> ichiga qo'shing
     (usiz subtitr chiqmaydi — IIS .vtt ni bermaydi):
         <remove fileExtension=".vtt" />
         <mimeMap fileExtension=".vtt" mimeType="text/vtt" />
     <staticContent> bo'lmasa — </system.webServer> dan oldin:
         <staticContent>
           <remove fileExtension=".vtt" />
           <mimeMap fileExtension=".vtt" mimeType="text/vtt" />
         </staticContent>
     Apache (XAMPP) bo'lsa — hech narsa kerak emas (.htaccess repoda).
  3. Video git'da bo'lmasa (A-3, 95 MB dan katta): kompyuteringizdan
       Copy-Item "E:\ai projects\lims-sevru\public\manuals\LIMS_video_uz.mp4" "\\192.168.26.8\xampp\htdocs\LIMS\public\manuals\"
  4. powershell -ExecutionPolicy Bypass -File deploy\tekshir_versiyalar.ps1
       → «Farq qiladi: 0», «public\build: Paket 35 bilan yig'ilgan»
  5. Brauzerda Ctrl+F5 → «Foydalanish yo'riqnomasi».
