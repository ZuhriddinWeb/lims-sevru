 PAKET 46 — SINOV PROFILI TANLANGANDA ELEMENTLAR DARHOL BELGILANADI
 2026-11-27   (Paket 45 dan keyin yoyiladi)
===========================================================================

NIMA TUZATILDI
---------------------------------------------------------------------------
 Namunalar → «Namuna ro'yxatga olish» (va tahrirlash) formasida «Sinov profili»
 tanlanganda «Aniqlanadigan elementlar» maydoni profil elementlari bilan darhol
 to'ldiriladi. Keyin qo'lda qo'shish/olib tashlash mumkin.
 (Avval elementlar faqat saqlashda, maydon bo'sh qolsa, serverda qo'shilardi —
 formada ko'rinmasdi.)
 Xuddi shunday «Sinov obyektlari» formasida ham.
 Profil almashtirilsa — elementlar yangi profilnikiga almashadi.

 Faqat interfeys. Bazaga o'zgarish YO'Q (migratsiya yo'q, seeder yo'q).

1. LOKAL KOMPYUTERDA
---------------------------------------------------------------------------
  1) Zipni loyiha ildiziga yoying (OQISH.txt siz).
  2) npm run build
  3) Tekshirish: Namunalar → «Namuna ro'yxatga olish» → Sinov profili: «bo'tana Au»
     → «Aniqlanadigan elementlar» da Au belgilanishi kerak.
  4) git add -A ;  git add -f public/build ;  git commit -m "Paket 46" ;  git push
  (tekshir_versiyalar.ps1 «Paket 45» belgisini tekshiradi — bu paketda yangi belgi yo'q.)

2. SERVERDA
---------------------------------------------------------------------------
     git fetch
     git reset --hard origin/main
     php artisan optimize:clear
  Brauzerda Ctrl+F5.

 Eslatma: profil elementlari sahifa ochilganda bir marta yuklanadi. Admin profil
 elementlarini o'zgartirsa — formadan oldin sahifani yangilang (F5).
