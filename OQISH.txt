PAKET 43 — Filtr saqlanadi                                     (2026-11-26)
============================================================
NIMA O'ZGARDI
-------------
Namunalar sahifasida (va shu tuzilishdagi boshqa ro'yxatlarda: katalog, uskunalar,
foydalanuvchilar va h.k.) filtr, qidiruv matni va tartib endi «Tozalash» tugmasi
bosilmaguncha saqlanadi:
  - namuna ichiga kirib «Ortga» qaytganda;
  - boshqa menyuga o'tib qaytganda;
  - sahifani yangilaganda (F5) yoki ertasi kuni kirganda ham.
Saqlangan filtr bo'lsa, filtr paneli ochiq turadi va «Filtrlar 1» belgisi ko'rinadi.
Sahifa raqami (2, 3-sahifa) brauzer oynasi yopilguncha eslab qolinadi.
Har foydalanuvchining filtri alohida (bitta kompyuterda boshqa xodim kirsa — o'zinikisi).
Saqlash brauzerda; bazaga hech narsa yozilmaydi.

Fayllar: resources\js\composables\useCrud.js, resources\js\components\crud\CrudPage.vue
         + deploy fayllari (versiya belgisi, ro'yxatlar).

A. LOKALDA
----------
1. Zipni loyiha papkasiga yoying (ustiga yozilsin), OQISH.txt ni o'chiring.
2. npm run build
3. powershell -ExecutionPolicy Bypass -File deploy\tekshir_versiyalar.ps1
     → «public\build: Paket 43 bilan yig'ilgan»
4. Ctrl+F5 → Namunalar → Status «Ishda» → namunaga kiring → ortga: filtr turibdi.
5. git add -A ; git restore --staged storage/logs/laravel.log ; git add -f public/build
   git commit -m "Paket 43: filtr saqlanadi" ; git push

B. SERVERDA
-----------
   git fetch origin ; git reset --hard origin/main
   "D:\php files\php.exe" artisan optimize:clear ; iisreset ; Ctrl+F5
