 6. VEB-SERVER
---------------------------------------------------------------------------
 Sayt papkasi = loyihaning  public  papkasi (loyiha ildizi EMAS).

 6A. XAMPP / APACHE (hozirgi serverdagidek)
      C:\xampp\apache\conf\httpd.conf — oxiriga:
         Listen 3010
      C:\xampp\apache\conf\extra\httpd-vhosts.conf — oxiriga:
         <VirtualHost *:3010>
             DocumentRoot "C:/xampp/htdocs/LIMS/public"
             <Directory "C:/xampp/htdocs/LIMS/public">
                 AllowOverride All
                 Require all granted
             </Directory>
         </VirtualHost>
      httpd.conf da  LoadModule rewrite_module modules/mod_rewrite.so  qatori izohsiz (# siz) bo'lsin.
      XAMPP Control Panel → Apache → «Svc» (xizmat sifatida — server qayta yonsa o'zi turadi) → Start.
      Firewall (Administrator cmd):
         netsh advfirewall firewall add rule name="LIMS 3010" dir=in action=allow protocol=TCP localport=3010
      php.ini yoki .conf o'zgarsa: Apache Stop → Start.

 6B. IIS (XAMPP o'rniga)
      PowerShell:  Install-WindowsFeature Web-Server, Web-CGI, Web-Static-Content, Web-Default-Doc, Web-Http-Errors, Web-Mgmt-Console
      URL Rewrite moduli — iis.net dan alohida o'rnating (usiz har sahifa 404).
      PHP — NTS versiya (1.2 dagi nts drayverlar), masalan C:\php:
         %windir%\system32\inetsrv\appcmd set config /section:system.webServer/fastCgi /+[fullPath='C:\php\php-cgi.exe']
         %windir%\system32\inetsrv\appcmd set config /section:system.webServer/handlers /+[name='PHP_via_FastCGI',path='*.php',verb='*',modules='FastCgiModule',scriptProcessor='C:\php\php-cgi.exe',resourceType='Either']
      Sayt:
         %windir%\system32\inetsrv\appcmd add apppool /name:LIMS /managedRuntimeVersion:""
         %windir%\system32\inetsrv\appcmd add site /name:LIMS /bindings:http/*:3010: /physicalPath:C:\xampp\htdocs\LIMS\public
         %windir%\system32\inetsrv\appcmd set app "LIMS/" /applicationPool:LIMS
         if not exist public\web.config copy deploy\web.config.example public\web.config
         icacls storage         /grant "IIS AppPool\LIMS":(OI)(CI)M /T
         icacls bootstrap\cache /grant "IIS AppPool\LIMS":(OI)(CI)M /T
         iisreset

 Brauzerda:  http://192.168.X.Y:3010  → kirish sahifasi → admin bilan kiring.

 8. ZAXIRA NUSXA JADVALI  (har kuni 23:30)
---------------------------------------------------------------------------
 8.1  Papka va SQL Server xizmatiga yozish ruxsati (nusxani SQL Server xizmati yozadi):
        mkdir D:\LIMS_backup
        icacls D:\LIMS_backup /grant "NT Service\MSSQLSERVER":(OI)(CI)M
      (SQL Express: "NT Service\MSSQL$SQLEXPRESS")

 8.2  SSMS — vazifani bajaradigan SYSTEM hisobiga faqat zaxira olish huquqi:
        USE [lims_zavod2];
        IF NOT EXISTS (SELECT 1 FROM sys.database_principals WHERE name = N'NT AUTHORITY\SYSTEM')
            CREATE USER [NT AUTHORITY\SYSTEM] FOR LOGIN [NT AUTHORITY\SYSTEM];
        ALTER ROLE db_backupoperator ADD MEMBER [NT AUTHORITY\SYSTEM];

 8.3  Vazifa (Administrator cmd):
        schtasks /Create /TN "LIMS Backup" /SC DAILY /ST 23:30 /RU SYSTEM /RL HIGHEST /F /TR "sqlcmd -S localhost -E -C -Q \"BACKUP DATABASE [lims_zavod2] TO DISK = N'D:\LIMS_backup\lims_zavod2.bak' WITH INIT\""
      (nomlangan nusxa: -S localhost\SQLEXPRESS)
      Tekshirish:  schtasks /Run /TN "LIMS Backup"   → bir daqiqadan keyin D:\LIMS_backup\lims_zavod2.bak
 Haftasiga bir marta nusxani boshqa kompyuter yoki diskka ko'chiring.

 11. XATOLAR JADVALI
---------------------------------------------------------------------------
 lims:install-state «existing» / «foydalanuvchilar bor»
      .env boshqa (ishlab turgan) bazaga qaraydi — DB_DATABASE ni tekshiring. TO'XTANG.
 «Bazada boshqa dasturning jadvallari bor»
      LIMS uchun alohida bo'sh baza (2-bo'lim), DB_DATABASE ni o'zgartiring.
 «could not find driver»
      pdo_sqlsrv yoqilmagan yoki mos emas: ts/nts, x64, 82/83 (1.2). php -m | findstr sqlsrv
 «SSL … certificate»                      .env: DB_TRUST_SERVER_CERTIFICATE=true
 «Login failed for user»                  Mixed Mode / parol / login bazaga biriktirilmagan (2-bo'lim)
 ulanish vaqti tugadi                     TCP/IP, 1433, firewall, DB_HOST; SQLEXPRESS da DB_PORT ni o'chiring
 «There is already an object named …» (migrate)
      Baza bo'sh emas edi. Bo'sh bazada boshidan boshlang (2-bo'lim).
      database\migrations ichida begona migratsiya fayli yo'qligini tekshiring.
 Sahifa oq / 500                          storage\logs\laravel-*.log; APP_KEY; IIS — icacls (6B)
 Har sahifada 404                         Apache: AllowOverride All, mod_rewrite; IIS: URL Rewrite, web.config
 API xatolari, kirish ishlamaydi          .env: APP_URL va CORS_ALLOWED_ORIGINS = brauzerdagi manzil (port bilan);
                                          php artisan optimize:clear; brauzer cookie'larini tozalang
 Fayl/rasm ochilmaydi                     php artisan storage:link
 Excel: «zip kengaytmasi yoqilmagan»      php.ini: extension=zip; Apache Stop/Start
 Yordamchi javob bermaydi                 HELP_ENABLED=true; php artisan lims:upgrade; optimize:clear
 503 «Service Unavailable»                yangilash o'rtada to'xtagan: php artisan up
