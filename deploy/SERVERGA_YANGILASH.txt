 C) KEYIN — har bir serverda bir marta
---------------------------------------------------------------------------
  1. PHP «zip» kengaytmasi (Excel'ga yuklash, svodka) — skript 2-qadamda «[!] zip» desa:
        C:\xampp\php\php.ini  →  ;extension=zip  →  extension=zip  →  saqlang → Apache Stop/Start
        tekshirish:  php -m | findstr /i zip

  2. Rejalashtirgich (skript 11-qadamda «[!] LIMS Scheduler yo'q» desa):
        schtasks /Create /TN "LIMS Scheduler" /SC MINUTE /MO 1 /RU SYSTEM /RL HIGHEST /F /TR "\"C:\xampp\php\php.exe\" \"C:\xampp\htdocs\LIMS\artisan\" schedule:run"
     Tekshirish:  php artisan schedule:list  → interlab:sync, sample-requests:expire, lims:check-reminders

  3. Rollar va ruxsatlar (admin) — yangi ruxsatlar faqat yangi yaratilganda rollarga beriladi.
     Sizdagi rollar boshqacha bo'lsa — «Rollar va ruxsatlar» sahifasida moslang.

  4. Buyurtmachi bo'limlar va portal (Paket 15, 24, 27):
     Foydalanuvchilar → rol «Buyurtmachi (bo'lim)» → Kataloglar → Buyurtmachi bo'limlar → biriktirish.
     Boshqaruv → «Portal sozlamalari» — buyurtmachi nimani ko'radi.

  5. Guruhlar (Paket 30): «Foydalanuvchilar»da qabul qiluvchi xodimlarning «Guruh» maydoni
     to'g'ri bo'lsin (har guruh faqat o'z buyurtmalarini ko'radi; guruhsiz xodim — hammasini).

  6. Svodka (Paket 29–31):
     a) «Svodkalar» → bo'limni tanlang → «Sozlama» → svodkani yoqing, navbatchilik vaqtlari.
     b) Spravochnik (bloklar va nuqtalar) — buyurtmachi o'zi kiritadi. NKMK GMZ-3 TNB uchun
        tayyor ro'yxat bor:
           php artisan svodka:spravochnik TNBGMZ3 --dry-run
           php artisan svodka:spravochnik TNBGMZ3
        (bo'lim kodi — Kataloglar → Buyurtmachi bo'limlar; noto'g'ri kod bo'lsa ro'yxatni chiqaradi)
     c) Svodkani ko'rish (masalan, laboratoriya boshlig'iga): admin → «Svodkalar» →
        «Svodkani ko'ruvchilar» → foydalanuvchini qo'shish. Rol yaratish shart emas.
     d) Natija svodkaga chiqmasa — sabab:  php artisan svodka:tekshir TNBGMZ3 --kun=30
     e) «Natijalar tahlili (AI)» — laboratoriya boshlig'i rolida avtomatik; boshqa xodimga — «Svodkani
        ko'ruvchilar» ro'yxati orqali yoki rolga «Natijalar tahlili (AI) — Ko'rish» ruxsati.

  7. Smenalar (Rahbariyat paneli) — avval sozlanmagan bo'lsa.

  8. Ixtiyoriy .env sozlamalari (o'zgartirgach: php artisan optimize:clear):

        SAMPLE_REQUEST_EXPIRE_DAYS=14    buyurtma muddati, kun
        CORS_ALLOWED_ORIGINS=...         sayt manzili (yangi domen/port/HTTPS bo'lsa)

  9. Tekshirish ro'yxati (brauzerda, Ctrl+F5):
     [ ] kirish, chap menyu to'liq; admin o'zgartirgan menyu nomlari joyida

 D) MUAMMO BO'LSA — ORTGA QAYTISH
---------------------------------------------------------------------------
  Avval xato matnini yuboring — ko'p hollarda tuzatib, skriptni qayta ishga tushirish kifoya
  (bajarilgan qadamlar takrorlanmaydi). To'liq ortga qaytish kerak bo'lsa:

     php artisan down
     sqlcmd -S localhost -E -Q "ALTER DATABASE [BAZA] SET SINGLE_USER WITH ROLLBACK IMMEDIATE; RESTORE DATABASE [BAZA] FROM DISK = N'BAZA_2026-11-03_1630.bak' WITH REPLACE; ALTER DATABASE [BAZA] SET MULTI_USER"
        (baza nomi va fayl — 4-qadamda skript ko'rsatgan; yoki SSMS: Restore Database…)
     git checkout <B-1 da yozilgan commit>
     php artisan optimize:clear
     php artisan up
  Keyinroq qayta yangilash:  git checkout main  (yoki master)  →  git pull  →  B-bo'lim.

  Ishlab turgan bazada  php artisan migrate:rollback  ISHLATMANG — zaxiradan tiklang.
